模型目录

倍率 = 扣分系数（越小越省）。模型名原样透传；上游对不认识的模型会静默回落到默认模型，看回包 model 字段确认。
模型 id名称倍率实测积分/次上下文能力
—
计费（真实扣费实测）：
· 对话：每次保底 1 分；输入（prompt）和输出（completion）都要计费， 思考 token 计入输出。
　实测（deepseek x3.0，输出固定 ~20 tok，只改输入长度）： 95 输入 → 1 分（保底）｜24k 输入 → 21 分｜240k 输入 → 184 分。
　⇒ 长对话历史才是主要成本：agent / 多轮对话每轮都会把完整历史当 prompt 重发， 压上下文比压输出省钱得多。
· 生图：110 分/次（三个生图模型同价，实测）。
· 思考等级实测：reasoning_effort 各档位对思考长度影响不显著且不单调 （deepseek 五档 rtok=248/203/153/275/133）——推理模型无论如何都会思考， 控成本请直接压 max_tokens。
· 「实测积分/次」来自账号真实扣费流水。

⚠ 主域名偶发解析不了？主域名的解析链必须经 your-dns.example（DNSHE 免费 DNS， ns.example-dns.org）这一跳，它在国内偶发超时 → 客户端报 getaddrinfo ENOTFOUND your-domain.example。 域名本身和证书都没问题，只是这一跳会抖。
想继续用主域名（推荐，域名一字不改、证书照常有效）：
① 最稳：客户端机器 hosts 加一行 203.0.113.10 your-domain.example —— 实测直连 + SNI 用原域名 返回 200、证书有效，绕过 example-dns.org 那一跳；
② 最省事：把客户端/路由器的 DNS 改成 114.114.114.114（实测 15/15 稳定， 次选 8.8.8.8），域名照原样用。
备用域名（额外兜底，由 nip.io/sslip.io 权威 DNS 解析，绕开 example-dns.org， 不影响主域名，可不用）：
③ https://loomy.your-server-ip.nip.io/v1 ④ https://your-server-ip.sslip.io/v1
